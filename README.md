# SMA - Simulação e Métodos Analíticos

Repositório com os trabalhos desenvolvidos ao longo da disciplina de Simulação e Métodos Analíticos.

Cada entrega tem sua própria pasta, nomeada conforme o módulo correspondente.

## Módulos

- [M4 - Desenvolvimento de Simulador para uma Fila](<M4 - Desenvolvimento de Simulador para uma Fila>): simulador de fila G/G/c/K por eventos discretos, com gerador de números pseudoaleatórios (Método Congruente Linear), tratamento dos eventos de chegada/saída e cálculo da distribuição de probabilidades dos estados da fila.
- [M6 - Desenvolvimento de Simulador para Filas em Tandem](<M6 - Desenvolvimento de Simulador para Filas em Tandem>): extensão do simulador do M4 para uma rede de filas G/G/c/K com topologia genérica, com roteamento probabilístico de clientes entre filas conectadas.
- [T1 - Avaliação de Aprendizagem](<T1 - Avaliação de Aprendizagem>): generalização do simulador do M6 para carregar qualquer topologia de rede de filas a partir de um arquivo `.yml`, no mesmo estilo do simulador do módulo 3.
